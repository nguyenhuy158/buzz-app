# Saved and To-dos

Keep messages for later and manage your own tasks.

## Getting started

1. Choose **Save for later** or **Add to To-dos** in a message menu.
2. Open **Saved** or **To-dos** in the dock. Add tasks, set reminders, or mark them done.
3. Use **Refresh** to get changes from your other devices.

This personal build needs the owner account and a sync server. Mac reminders
use the last sync, even after Quit. See [setup and limits](../../../docs/personal-lists.md).
